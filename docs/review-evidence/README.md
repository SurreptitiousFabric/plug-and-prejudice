# Human review evidence

Retain approved, non-sensitive review records here using `TEMPLATE.md`. Name a
record `YYYY-MM-DD-track-short-name.md`. A record is valid only for its exact
commit and review track.

Do not store credentials, private plugin source, personal configuration, live
malware, raw home-directory paths, access tokens, session identifiers, or
unredacted screenshots/logs. Prefer exact commands, bounded excerpts, hashes,
and links to public GitHub findings.

The implementer may prepare a draft, but the independent reviewer must author
or explicitly verify the observations and conclusion. An incomplete template
is not approval.
