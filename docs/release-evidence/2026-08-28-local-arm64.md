# Local ARM64 engineering evidence — 2026-08-28

not final package provenance, a signed release attestation, an independent
security review, or evidence for x86-64. The inspected Git base was
`56dcee89f024c40e4244e6ea35c2fdb1fd40411a` with uncommitted changes.

## Successful automated gates

The following completed successfully against the current working tree:

- `gofmt` cleanliness and `git diff --check`;
- `go test ./...` and `go test -race ./...`;
- `go vet ./...` and `go mod verify`;
- production dependency and third-party-notice verification;
- selective Python/JavaScript parser footprint verification on ARM64 and
  cross-built AMD64 binaries;
- CPython and Node syntax-oracle comparison using trusted test samples only;
- pinned `govulncheck v1.7.0`, reporting no known reachable vulnerabilities;
- least-privilege GitHub Actions policy verification;
- byte-reproducible native ARM64 static-PIE builds with no runtime interpreter
  or shared-library imports;
- Arch PKGBUILD rendering, shell parsing, makepkg `.SRCINFO` parsing, pinned
  input rejection, and fixed install-path checks; and
- a native development-only `makepkg` build from an integrity-pinned source
  snapshot, including the package `check()` suite, followed by exact Pacman
  identity/inventory, executable-mode, architecture, traversal-path, and static
  ELF verification; this exposed and fixed missing `-buildvcs=false` handling
  for VCS-free release archives; and
- an unprivileged user-namespace Pacman lifecycle from development versions
  0.0.1 to 0.0.2: offline package validation, isolated installation,
  namespace-root ownership and package-file records, upgrade, broker version
  version agreement for both scanner and broker, removal, and post-removal
  file/database absence; the host package
  database and `/usr/bin` were not modified; and
- five-second fuzz campaigns for Python, JavaScript, report decoding,
  inventory byte scanning, diagnostic normalization, and bounded JSON encoding.

## Live containment observations

Focused tests established the configured live systemd scope, verified runtime,
memory, and task limits, and passed Bubblewrap isolation, timeout, oversized
stdout, and oversized diagnostic cancellation cases.

The controlled same-filesystem bind-mount fixture skipped because this kernel
configuration forbids the unprivileged mount operation. The implementation and
skip behavior remain tested, but this run is not positive live nested-mount
evidence.
